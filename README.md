# Hi, I'm Ghislain 👋

I make AI-assisted development **predictable**. On a platform used by 25+ feature teams I build agent harnesses with fixed phases and quality gates, MCP servers that give agents real context, and a tested toolkit of skills and agents. Before that came 11+ years of test automation, and I still teach Playwright.

- 🤖 **AI engineering**: agent harnesses, MCP servers, Copilot skills & agents, all tested in CI
- 🛠️ **Platform engineering**: self-service test environments, one-click releases & hotfixes
- 🎭 **Test automation**: test strategy, frameworks and test data, from Selenium to Playwright
